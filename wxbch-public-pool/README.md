# WxBCH Public Pool — Umbrel

This directory is the Umbrel app wrapper for the BCHN-native pool in the repository root.

- Web/API: port 3334 through Umbrel app proxy
- Stratum V1: port 3333
- BCHN RPC: host port 8332 by default
- BCHN ZMQ: host port 28332 by default

The pool image is built by GitHub Actions and published to GHCR.

# WxBCH Public SOLO

Bitcoin Cash Node + Solo Mining Umbrel app.

## Status

Early development. The app packages Bitcoin Cash Node with a local solo-mining Stratum service and web dashboard.

## Components

- Bitcoin Cash Node (BCHN)
- Local BCH RPC/ZMQ integration
- Solo Stratum server
- Lightweight dashboard
- Persistent Umbrel app data

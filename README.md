# WxBCH Community App Store

Umbrel Community App Store for **WxBCH Public SOLO**.

## Add this store to Umbrel

Use the following Git repository URL when adding a Community App Store:

`https://github.com/Wx256-MIN/WxBCH-Public_SOLO.git`

Umbrel Community App Stores use an `umbrel-app-store.yml` at the repository root and require each app directory to use the store ID as its prefix. This store uses ID `wxbch`, and the app is `wxbch-public-solo`. citeturn0search0turn0search2

## App

**WxBCH Public SOLO** provides:

- Bitcoin Cash Node 29.2.0
- BCH-native solo Stratum mining
- CashAddr miner usernames
- Web dashboard
- TCP 3333 Stratum endpoint
- TCP 8333 BCH P2P endpoint

This is an independent community project and is not an official Umbrel or Bitcoin Cash Node project.
